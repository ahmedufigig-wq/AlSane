# الصانع - مشروع Android
مشروع أولي قابل للبناء عبر GitHub Actions، يعمل بواجهة عربية محلية دون إنترنت.

## البناء من الهاتف
1. افتح تبويب Actions وانتظر تشغيل Build Al-Sane APK بعد رفع الملفات.
2. افتح عملية البناء الناجحة ثم نزّل Artifact باسم AlSane-debug-apk.
3. فك الضغط وثبّت app-debug.apk على هاتف Android.

## ملاحظات مهمة
- البيانات محفوظة محلياً داخل التطبيق عبر التخزين المحلي.
- العملة الافتراضية ريال يمني.
- هذه نسخة تأسيسية تحتاج اختباراً عملياً وإضافات محاسبية قبل اعتمادها للحسابات التجارية النهائية.
- لا تحذف التطبيق قبل تصدير نسخة احتياطية؛ حذف التطبيق قد يحذف بياناته المحلية.
