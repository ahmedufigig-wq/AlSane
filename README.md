# مخزني – Makhzani
تطبيق Android عربي لإدارة المخزون والمبيعات والحسابات المحلية دون اتصال بالإنترنت.

## البناء من الهاتف
1. افتح [عمليات البناء على GitHub](https://github.com/ahmedufigig-wq/AlSane/actions).
2. افتح أحدث عملية باسم **Build Makhzani APK** وانتظر ظهور Success.
3. من قسم Artifacts نزّل **Makhzani-debug-apk**.
4. فك ضغط الملف وثبّت app-debug.apk على هاتف Android.

## الحالة والحدود الحالية
- واجهة عربية محلية ضمن Android WebView.
- حفظ البيانات الحالي يعتمد على localStorage داخل التطبيق؛ لم يتم تحويله بعد إلى قاعدة بيانات Room/SQLite.
- توجد وظائف أساسية للمنتجات والمبيعات والديون والموردين والمشتريات والصندوق والتقارير والنسخ الاحتياطي، لكنها ليست بعد نظاماً محاسبياً شاملاً مدققاً.
- نجاح بناء APK لا يثبت صحة كل الوظائف المالية. اختبر البيانات والنسخ الاحتياطي على نسخة تجريبية قبل إدخال حسابات متجر حقيقية.
- احتفظ بنسخة احتياطية قبل حذف التطبيق أو إعادة تثبيته.
